# 选中文本 AI 翻译（Chrome 扩展）

在网页上选中外文 → 右键 → 右上角弹出中文译文。

基于智谱 GLM 的免费模型，一个 `background.js` 就能跑起来的小项目。

## 功能

- 右键菜单「翻译选中的文本」，只在你划词后才出现
- 悬浮结果框：**原文 + 译文**对照，可拖动、一键复制、`Esc` 或 `✕` 关闭
- 先弹「翻译中…」，拿到结果原地替换，不会让你干等
- 关闭后再次翻译，弹框出现在你上次拖到的位置（同一标签页内有效）
- 用 Shadow DOM 隔离样式，不会和目标网页的 CSS 互相污染
- 连续翻译不会叠一屏框：每次注入前先清掉上一个

## 安装

1. 下载或克隆本仓库
2. 把 `config.example.js` 复制一份、改名为 **`config.js`**，填入你自己的 API Key
   （在 [智谱开放平台](https://open.bigmodel.cn/) 注册后进「API Keys」获取，免费模型无需付费）
3. 打开 `chrome://extensions` → 右上角开启「开发者模式」→ 点「加载已解压的扩展程序」→ 选择本目录
4. 在任意网页选中一段外文 → 右键 → 「翻译选中的文本」

改完 `config.js` 或代码后，要回 `chrome://extensions` 点本扩展卡片上的「重新加载」才生效。

## 配置

`config.js`：

```js
self.TT_CONFIG = {
  api_key: "你的 API Key",
  model: "glm-4-flash",
};
```

可用的免费文本模型（`model` 字段随便换）：`glm-4-flash`、`glm-4.5-flash`、`glm-4.7-flash`……

如果经常看到 `接口错误：HTTP 429 - 该模型当前访问量过大`，说明该模型当前并发被占满，换一个免费模型即可，不是代码问题。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展的「说明书」：版本、权限、入口文件、图标 |
| `background.js` | 后台 service worker：注册右键菜单、请求接口、把弹框注入页面 |
| `config.js` | **你的私密配置**，已被 `.gitignore` 忽略，不会进 git |
| `config.example.js` | 配置模板，提交进仓库的就是这一份 |
| `icon128.png` 等 | 扩展图标 |

## 实现要点

几个容易踩坑、写在注释里的关键点：

- **接口请求必须放在 service worker 里发。** 注入到页面的脚本发 `fetch` 会受目标网页的 CORS 限制，后台不受。
- **注入的函数会被序列化。** `chrome.scripting.executeScript({ func })` 是把函数转成字符串送到页面里重新执行，所以它读不到 `background.js` 里的任何变量，只能靠参数传入。
- **数据用 `textContent` 写，不用 `innerHTML`。** 模型返回的内容要当数据而不是 HTML 处理，避免注入。
- **拖动用 `setPointerCapture`，不往 `document` 挂全局监听。** 否则每次翻译都会多留一份监听器。

## 隐私

只有你主动划选并点击翻译的那段文本会被发送到智谱 AI 的接口。除此之外不收集、不上传任何数据。

## 已知限制

- `chrome://` 开头的页面、Chrome 扩展商店、内置 PDF 阅读器里无法注入脚本，这是浏览器限制
- 免费模型有并发限制，高峰期可能返回 429，稍等重试或换模型
- 译文由大模型生成，仅供参考
可以幽默一些
